How to Change Admin Credentials

1. Go to your GitHub repository

2. Open admin/index.html

3. Find the admins array in the JavaScript section

4. Update or add new admin credentials:

const admins = [
    { email: 'admin@avmsabu.com', password: 'newpassword123' },
    { email: 'youremail@example.com', password: 'yourpassword' }
];

5. Commit the changes

6. Wait 1-2 minutes for Vercel to deploy
